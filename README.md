# 🏰 ป้อมปราการธาตุ (Elemental Tower Defense)

เกม Tower Defense สไตล์การ์ตูนน่ารัก สร้างด้วย HTML5 ไฟล์เดียว (ไม่มี dependency ภายนอก)

## วิธีเล่น
เปิดไฟล์ [`tower_defense.html`](./tower_defense.html) ด้วยเว็บเบราว์เซอร์ได้เลย

## ฟีเจอร์
- 🗺️ 10 ด่าน ความยากเพิ่มขึ้นเรื่อยๆ จบด้วยบอสมังกรในด่าน 10
- ⚔️ หอคอย 5 ธาตุ: 🔥 เพลิง, 💧 สายชล, 🪨 ศิลา, 🌪️ วายุ, ⚡ สายฟ้า — แต่ละอันอัพเกรดได้ 5 เลเวล และขายคืนได้
- 🎨 กราฟิกการ์ตูนน่ารัก วาดด้วย Canvas 2D ทั้งหมด
- 🔊 เสียงเอฟเฟกต์สังเคราะห์ด้วย Web Audio API (ไม่ใช้ไฟล์เสียงภายนอก)
- 💾 บันทึกความคืบหน้า (ดาวที่ได้ในแต่ละด่าน และด่านที่ปลดล็อก) ลง localStorage
