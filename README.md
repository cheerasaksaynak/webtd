# 🏰 ป้อมปราการธาตุ (Elemental Tower Defense)

เกม Tower Defense สไตล์การ์ตูนน่ารัก สร้างด้วย HTML5 + JavaScript ล้วน (ไม่มี dependency ภายนอก ไม่ต้อง build)

## วิธีเล่น
เปิดไฟล์ [`tower_defense.html`](./tower_defense.html) ด้วยเว็บเบราว์เซอร์ได้เลย (ต้องเก็บโฟลเดอร์ `css/` และ `js/` ไว้ข้างๆ ไฟล์นี้)

## โครงสร้างโค้ด
| ไฟล์ | หน้าที่ |
|---|---|
| `tower_defense.html` | โครงหน้าเว็บ |
| `css/style.css` | สไตล์ทั้งหมด |
| `js/config.js` | ค่าคงที่ ข้อมูลนักรบ/ศัตรู (HP, ความเร็ว), การสร้างเส้นทางและคลื่นศัตรู, ความยากต่อด่าน (`levelConfig`), เซฟ |
| `js/themes.js` | ธีมของ 10 ด่าน (สี พื้น เส้นทาง ของตกแต่ง เอฟเฟกต์บรรยากาศ) |
| `js/game.js` | สถานะเกม, สปอนศัตรู, การเคลื่อนที่, การยิง, update loop |
| `js/scenery.js` | วาดพื้นหลัง ของตกแต่ง เส้นทาง และเอฟเฟกต์บรรยากาศ |
| `js/render.js` | วาดนักรบบนแผนที่ กระสุน อนุภาค และ `render()` |
| `js/warriors.js` | รูปนักรบ 5 ธาตุ |
| `js/monsters.js` | รูปมอนสเตอร์ตามธีม (`THEME_MONSTERS`) และบอสมังกร |
| `js/ui.js` | วางนักรบ, อินพุต, HUD, เมนู, เสียง, main loop |

## ฟีเจอร์
- 🗺️ 10 ด่าน แต่ละด่านมีธีมพื้นหลัง เส้นทาง และบรรยากาศต่างกัน (ทุ่งหญ้า, ป่าไม้, ทะเลทราย, ชายหาด, เมืองหิมะ, ถ้ำลาวา, หนองน้ำมนตร์, ถ้ำคริสตัล, เมืองบนฟ้า, ปราสาทมังกร) จบด้วยบอสมังกรในด่าน 10
- 👾 มอนสเตอร์เปลี่ยนรูปร่างตามธีมของแต่ละด่าน (เช่น หมีและผึ้งในทุ่งหญ้า, ยักษ์หิมะในเมืองหิมะ, โครงกระดูกและอัศวินเกราะในปราสาท) เลือดของมอนสเตอร์เพิ่มขึ้นทั้งตามด่านและตามคลื่น
- ⚔️ นักรบ 5 ธาตุ: 🔥 เพลิง, 💧 สายชล, 🪨 ศิลา, 🌪️ วายุ, ⚡ สายฟ้า — แต่ละอันอัพเกรดได้ 5 เลเวล และขายคืนได้
- 🎨 กราฟิกการ์ตูนน่ารัก วาดด้วย Canvas 2D ทั้งหมด
- 🔊 เสียงเอฟเฟกต์สังเคราะห์ด้วย Web Audio API (ไม่ใช้ไฟล์เสียงภายนอก)
- 💾 บันทึกความคืบหน้า (ดาวที่ได้ในแต่ละด่าน และด่านที่ปลดล็อก) ลง localStorage
